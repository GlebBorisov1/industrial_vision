# Dataset Card: PPE Detection Dataset

## Название набора
PPE Detection Dataset (3-Class) — версия 1.0.

## Назначение
Набор данных предназначен для обучения и валидации моделей детекции средств индивидуальной защиты (СИЗ) в рамках проекта по контролю безопасности на промышленной территории.

## Классы
*   `0: helmet` — защитная каска на голове человека.
*   `1: head` — голова человека без каски (нарушение).
*   `2: vest` — сигнальный/защитный жилет на туловище.

## Размер
*   Всего изображений: ~15 500 (согласно источнику).
*   Тестовая выборка (использована для валидации): 2 751 изображение, 10 862 размеченных объекта.

## Источники
*   Открытый датасет на платформе Hugging Face: [`jhboyo/ppe-dataset`](https://huggingface.co/datasets/jhboyo/ppe-dataset)..
*   Лицензия: MIT (допускает использование в учебных и коммерческих целях).

## Разметка
*   Формат: YOLO (нормализованные координаты `x_center, y_center, width, height`).
*   Инструмент разметки: исходный автор датасета (информация недоступна).

## Split (Разделение)
*   Данные уже разделены автором датасета на `train` / `val` / `test`.
*   Для валидации в рамках проекта использовалась готовая папка `test` (2751 изображение).
*   **Важно:** данные не пересекаются между выборками (исключен data leakage).

## Hard negatives
Специфические hard negatives (например, люди в обычных кепках, оранжевые куртки вместо жилетов) не выделены в отдельную папку, но присутствуют в общем наборе данных.

## Ограничения
*   Преимущественно дневные сцены и хорошее освещение.
*   Отсутствует класс `person` (человек как целое), только отдельные элементы (голова, каска, жилет).
*   Возможен дисбаланс классов (например, касок больше, чем жилетов).
