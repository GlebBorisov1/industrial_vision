# Model Card: YOLO26n (PPE) и Baseline YOLOv8n

## 1. Модель для контроля СИЗ: YOLO26n (fine-tuned)

### Архитектура и обучение
*   **Архитектура:** YOLO26n (Ultralytics).
*   **Исходный checkpoint:** `yolo26n.pt` (предобучен на COCO).
*   **Данные:** `jhboyo/ppe-dataset` (см. Dataset Card).
*   **Параметры обучения:** 50 эпох, `imgsz=640`, `batch=16`, `patience=10`.
*   **Среда обучения:** Google Colab, GPU Tesla T4.

### Метрики качества (на test split)
| Метрика | Значение |
| :--- | :--- |
| **Precision** | 0.9137 (91.4%) |
| **Recall** | 0.8937 (89.4%) |
| **mAP@0.5** | 0.9492 (94.9%) |
| **mAP@0.5:0.95** | 0.6867 |

### Производительность (на CPU Intel Core i5-13420H)
*   **Скорость инференса (val):** ~78.3 мс/кадр (~12.7 FPS).
*   **Скорость на видео (P95):** ~82.0 мс/кадр (без учета cold start).

### Ограничения
*   Не детектирует людей целиком (только `head`, `helmet`, `vest`).
*   Обучена на датасете с преимущественно дневными сценами.
*   Возможны ложные срабатывания при плохом освещении или сильном перекрытии.

---

## 2. Baseline-модель: YOLOv8n (COCO)

### Назначение
Используется как базовая модель для детекции людей (`person`) и транспорта (`car`, `truck` и т.д.) на Этапе 3.

### Статус
*   **Fine-tuning на PPE:** **не выполнен**. Обучение было прервано из-за исчерпания лимитов Google Colab на 43-й эпохе.
*   В отчёте используется как **точка отсчёта по скорости и архитектуре**, а не как модель для оценки качества на PPE.

### Производительность (на CPU Intel Core i5-13420H)
*   **Скорость на видео (P95):** ~89.9 мс/кадр.
*   **Размер:** ~6.1 МБ.

---

## Сравнение и вывод
| Параметр | YOLO26n (PPE) | YOLOv8n (COCO) |
| :--- | :--- | :--- |
| **Задача** | Детекция СИЗ | Детекция людей/транспорта |
| **mAP@0.5 (PPE)** | **0.9492** | — (не обучалась) |
| **P95 latency (CPU)** | **~82 мс** | ~90 мс |
| **Размер модели** | ~2.4M параметров | ~3.2M параметров |

**Вывод:** YOLO26n демонстрирует высокую точность (94.9% mAP@0.5) и по P95-задержке превосходит baseline YOLOv8n (~82 мс против ~90 мс), что делает её предпочтительным выбором для задачи контроля СИЗ на Edge-устройстве.
